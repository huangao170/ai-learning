# AI 短剧分镜生成器

输入一句故事梗概，自动生成短剧分镜（景别、画面描述、台词）。基于 DeepSeek 大模型和 FastAPI。

## 功能
- **两步式生成流程**：先由大模型将故事拆分为多个场景，再为每个场景生成详细分镜
- **异步并发**：使用 `asyncio.gather` 并发生成所有分镜，比串行调用快数倍
- **结构化输出**：强制大模型输出 JSON，便于程序进一步处理
- **参数校验**：使用 Pydantic 校验镜头数（1–10）、梗概长度等输入
- **错误处理**：超时与上游错误分别返回 504 / 502 状态码

## 技术栈
Python 3.12 · FastAPI · Pydantic · asyncio · OpenAI SDK · DeepSeek API

## 快速开始
```bash
pip install -r requirements.txt
cp .env.example .env    # 然后在 .env 中填入你的 DeepSeek API Key
fastapi dev api.py
```
打开 http://127.0.0.1:8000/docs 即可在线测试接口。

## 接口示例
`POST /storyboard`

请求：
```json
{"story": "被赶出豪门的女主三年后成为总裁，回来复仇", "shot_count": 3, "style": "真人"}
```

返回：
```json
{
  "梗概": "被赶出豪门的女主三年后成为总裁，回来复仇",
  "分镜": [
    {"镜头": 1, "景别": "远景", "画面": "滂沱雨夜，女主拖着行李箱站在豪宅门外……", "台词": ""},
    {"镜头": 2, "景别": "中景", "画面": "狭小的出租屋里，女主深夜对着电脑工作……", "台词": "总有一天，我会回去的。"},
    {"镜头": 3, "景别": "特写", "画面": "女主身穿西装推开豪门大门，眼神冷静……", "台词": "好久不见。"}
  ]
}
```

└── learning/               # 学习过程中的练习代码
